# Inspirations gameplay

## Role du document

Ce fichier sert seulement a garder les exemples de jeux cites par l'equipe.

Ce ne sont pas des regles a suivre et ce ne sont pas des features validees. Le
but est de garder une memoire commune des references qui ont inspire les idees :
survie, ressources, progression, minage, automatisation, defense, exploration et
jeu coop.

## References citees

| Jeu | Idee associee |
|---|---|
| Vampire Survivors | survie, vagues d'ennemis, progression rapide, armes automatiques |
| Deep Rock Galactic: Survivor | survivor-like avec nains, minage, ressources, progression et pression ennemie |
| Mine Survival | survie, recolte, craft, defense |
| Hybrid Animals | exploration, progression, creatures, monde ouvert |
| Mindustry | ressources, production, defense, automatisation |
| Don't Starve | survie, exploration, gestion du danger |
| YORG.io | defense de base, production, vagues |
| Astroneer | exploration, ressources, progression par equipement |
| Factorio | automatisation, chaines de production, optimisation |
| Albion Online | inspiration MMO/RPG : progression, ressources, economie, groupes, zones |

## Idees qui reviennent

- ressources ;
- level ups ;
- donjons ou zones speciales ;
- PvE ;
- PvP eventuel, a discuter ;
- survivor ;
- multiplayer ;
- minage ;
- automatisation ;
- defense ;
- inspiration MMO/RPG.

## Stack mentionnee

- React pour le front ;
- C++ pour la partie gameplay ;
- Node.js pour le serveur.

## Attention

Ces references servent a discuter et a comparer les envies de gameplay. Elles ne
doivent pas etre lues comme une obligation de copier ces jeux ou d'ajouter toutes
leurs mecaniques.
